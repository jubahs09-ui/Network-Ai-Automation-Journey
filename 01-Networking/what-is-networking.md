# What is Computer Networking?

## What I Learned
- Computer Networking is the practice of connecting computers and digital devices so they can communicate with each and share data and resources.

## My Understanding
- In my understanding, computer networking is a system that allows computers and other devices to communicate and exchange information with each other.

## Key Concepts
**Computer Networking** is a system that connects computers and digital devices so they can communicate, exchange data, and share resources.

## Real-World Example
- Computer networks can be categorized based on their geographical coverage and purpose.

- PAN ( Personal Area Network ) : A network that covers a very small area and is usually used to connect personal devices.
Example : Connecting a smartphone to wireless earbuds using Bluetooth.

- LAN ( Local Area Network ) : A network that covers a small area such as a home, laboratory, school, or office.
Example : A home Wi-Fi network connecting multiple devices to a printer.

- MAN ( Metropolitan Area Network ) : A network that covers a larger area such as multiple buildings within a city.
Example : A network connecting multiple university buildings or bank branches within the same city

- WAN ( Wide Area Network ) : A network that covers a large geographical area, such as multiple cities, countries, or even continents.
Example: The Internet, which connects networks around the world.
